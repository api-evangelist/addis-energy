# Addis Energy

> Addis Energy is a Somerville, Massachusetts deep-tech energy company, founded in January 2025 out
> of research in the MIT Department of Materials Science and Engineering, developing Stimulated
> Geologic Ammonia — injecting nitrogen, water and engineered fluids into iron-rich subsurface rock
> and using the earth's own heat and pressure as the reactor to produce ammonia underground rather
> than in a Haber-Bosch plant.

Generated by API Evangelist on 2026-09-07 from the live public surface at addisenergy.com. This is
a third-party profile: Addis Energy does not publish an llms.txt of its own (https://addisenergy.com/llms.txt
returned HTTP 404 on 2026-09-07).

## What Addis Energy is, for an agent's purposes

Addis Energy is NOT a software vendor. It sells no API, publishes no developer portal, issues no
API keys, ships no SDKs and runs no MCP server. Founders: Michael Alexander (CEO), Charlie Mitchell
(COO), Iwnetim Abate (Chief Science Officer), Yet-Ming Chiang (Chief Strategy Officer). Funding:
an $8.3M seed round plus a $4.5M ARPA-E award from the US Department of Energy; investors include
Engine Ventures, At One Ventures, Pillar VC, Voyager VC, Blindspot Ventures and Emerson Collective.

The only machine-readable interface it exposes is the WordPress core REST content API behind its
corporate website. That surface is genuinely public, anonymous and read-only — and it is the whole
of the API story here.

## The API surface

- [REST API root / route index](https://addisenergy.com/wp-json/): Self-describing discovery
  document. 218 routes across 9 namespaces at capture. This is the substitute for the
  documentation Addis Energy does not publish.
- Base URL: `https://addisenergy.com/wp-json`
- Authentication: none required for reading. Write methods use WordPress application passwords,
  which only a site administrator can mint — there is no path for a third party to obtain one.
- Format: JSON. Errors are `{code, message, data.status}`, NOT RFC 9457 problem+json.
- Pagination: `page` + `per_page` (1..100, rejected not clamped) with `X-WP-Total` and
  `X-WP-TotalPages` response headers, exposed cross-origin.
- Rate limits: none published, and no rate-limit header of any kind is returned. Treat as
  unmetered but fragile.

- [Posts](https://addisenergy.com/wp-json/wp/v2/posts): 13 published news and press-coverage posts.
- [Pages](https://addisenergy.com/wp-json/wp/v2/pages): 7 static pages — Home, Technology, News,

- [Media](https://addisenergy.com/wp-json/wp/v2/media): 73 attachments — photography, diagrams,
  team headshots, investor logos and press assets.
- [Categories](https://addisenergy.com/wp-json/wp/v2/categories): 3 terms — Press Coverage (11),
  Blog (2), Uncategorized (0).
- [Tags](https://addisenergy.com/wp-json/wp/v2/tags): route served, taxonomy empty (0 terms).
- [Users](https://addisenergy.com/wp-json/wp/v2/users): 2 public author records, `view` context only.
- [Search](https://addisenergy.com/wp-json/wp/v2/search): 20 searchable objects across posts and pages.
- [Types](https://addisenergy.com/wp-json/wp/v2/types) and
  [Taxonomies](https://addisenergy.com/wp-json/wp/v2/taxonomies): WordPress core only — Addis
  Energy registers no custom post type and no custom taxonomy.
- [oEmbed](https://addisenergy.com/wp-json/oembed/1.0/embed): oEmbed 1.0 for any addisenergy.com URL.

## Not available (verified absences, not gaps in this document)

- No OpenAPI, GraphQL SDL, AsyncAPI, WSDL or .proto is published by Addis Energy. The OpenAPI in
  this repository was derived by API Evangelist from the server's own route index.
- No MCP server, remote or stdio.
- No A2A agent card: `/.well-known/agent-card.json` and `/.well-known/agent.json` both 404.
- No `/.well-known/` document of any kind: security.txt, openid-configuration,
  oauth-authorization-server, api-catalog and ai-plugin.json all returned 404 on both
  addisenergy.com and www.addisenergy.com.
- No SDKs or client libraries in any registry; no GitHub organization
  (https://github.com/addisenergy returns 404).
- No pricing, no signup, no login, no status page, no changelog, no CLI, no sandbox, no webhooks.
- Comments are disabled site-wide (403 `rest_comment_disabled`); Contact Form 7 definitions are
  administrator-only (403 `wpcf7_forbidden`); site settings and the WordPress Abilities API are
  administrator-only (401 `rest_forbidden`).

## Etiquette

Every `wp-json` response carries `X-Robots-Tag: noindex`. The surface is reachable but the operator
has asked not to have it indexed. The whole corpus is 13 posts, 7 pages, 73 media items and 20
searchable objects — a complete crawl is four requests at `per_page=100`. Cache; do not poll. Use
`_fields` to trim responses and `_embed` to collapse round trips.
